# 此事应当重视 · 官话官说

说件小事，我替你重视。

**[打开官话官说](https://yaoyuan0zz.github.io/guanhua-guanshuo/)**

输入一个标题或主题，生成数千字一本正经的官话议论文章，也保留短句表达。基础版使用浏览器本地句库与规则，不调用大模型，不需要 API Key、登录或构建工具。

## 使用

下载仓库后，用现代浏览器打开 `index.html`。保持同目录的 CSS 和 JS 文件完整即可。也可在仓库根目录运行 `python3 -m http.server 8000`，访问本机 `http://localhost:8000`。

- 默认生成约3000字长文，可选约1000/3000/5000字；只输入标题即可。
- 输入停顿后自动生成，回车或按钮立即生成。
- 点选示例体验，复制结果或换个说法。
- 任意非空主题均可使用本地长文句库；可切换回短句表达。
- 输入上限300字，与输出篇幅分别计算，页面显示实际正文字符数。
- 窄屏上下排列，宽屏左右排列。

例：

> 晚上吃啥？
>
> 关于今晚用餐安排，现就具体餐食征求意见。

## 当前能力与限制

长文使用54段原创模板（3段开篇、48段正文、3段结尾），按论述顺序随机选取正文，单篇不重复同一段落。输出达到所选目标后保留完整段落，因此字数可能略高于标称值。长篇语料围绕主题进行通用议论，不等于理解任意主题。

短句基础库含80组示例场景、160条候选表达及部分常用别名。完整短句匹配会忽略空白和常用标点，每个已知场景的两条表达依次轮换。

不具备任意输入的语义理解。未知说法、复杂否定、引用或多事件组合通常保留原话，生成通用主题表达。长文也是模板组合，文风和覆盖范围仍在改进。内容仅供趣味表达，不作为正式通知或真实权威意见。

页面不调用外部服务，不保存输入历史，不引入第三方脚本、字体或统计。应用无模型调用费用；公开托管的额度和使用条件需要按所选平台另行核查。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 页面与样式 |
| `app.js` | 输入、复制和交互 |
| `engine.js` | 本地匹配与生成 |
| `article.js` | 长文原创模板与篇幅控制 |
| `corpus.js` | 场景与原创候选表达 |
| `tests/engine.cjs` | 规则与边界检查 |

执行检查：`node tests/engine.cjs` 与 `node tests/app.cjs`，无第三方依赖。后者为DOM夹具交互检查，不等于真实浏览器测试。

已检查80组示例匹配、候选轮换、部分别名、否定与指代防误匹配、空白和超长输入、展开论述。开发时实测了示例、复制、换说法、展开收起及否定回退。尚未全面验证所有设备、输入法与剪贴板权限。
