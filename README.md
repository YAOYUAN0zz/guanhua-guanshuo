# 此事应当重视 · 官话官说

说件小事，我替你重视。

**[打开官话官说](https://yaoyuan0zz.github.io/guanhua-guanshuo/)**

把日常小事改写成一本正经的官话表达。基础版使用浏览器本地句库与规则，不调用大模型，不需要 API Key、登录或构建工具。

## 使用

下载仓库后，用现代浏览器打开 `index.html`。保持同目录的 CSS 和 JS 文件完整即可。也可在仓库根目录运行 `python3 -m http.server 8000`，访问本机 `http://localhost:8000`。

- 输入停顿后自动转换，回车立即生成。
- 点选示例体验，复制结果或换个说法。
- 已匹配场景可以展开模板式论述。
- 窄屏上下排列，宽屏左右排列。

例：

> 晚上吃啥？
>
> 关于今晚用餐安排，现就具体餐食征求意见。

## 当前能力与限制

基础版含80组示例场景、160条候选表达及部分常用别名。完整短句匹配会忽略空白和常用标点，每个已知场景的两条表达依次轮换。

不具备任意输入的语义理解。未知说法、复杂否定、引用或多事件组合通常保留原话，生成通用主题表达。展开论述为模板稿，文风和覆盖范围仍在改进。内容仅供趣味表达，不作为正式通知或真实权威意见。

页面不调用外部服务，不保存输入历史，不引入第三方脚本、字体或统计。应用无模型调用费用；公开托管的额度和使用条件需要按所选平台另行核查。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 页面与样式 |
| `app.js` | 输入、复制和交互 |
| `engine.js` | 本地匹配与生成 |
| `corpus.js` | 场景与原创候选表达 |
| `tests/engine.cjs` | 规则与边界检查 |

执行检查：`node tests/engine.cjs`，无第三方依赖。

已检查80组示例匹配、候选轮换、部分别名、否定与指代防误匹配、空白和超长输入、展开论述。开发时实测了示例、复制、换说法、展开收起及否定回退。尚未全面验证所有设备、输入法与剪贴板权限。
